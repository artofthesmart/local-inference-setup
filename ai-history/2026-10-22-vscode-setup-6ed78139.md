## Summary

Added `copilot-local vscode` to install the official Ollama extension and configure VS Code for local Copilot generation and the privacy settings in the guide. The command checks VS Code 1.127 or newer, supports dry runs and non-interactive approval, backs up settings before modifications, merges JSONC while preserving comments and unrelated values, and confirms conflicts. Help, the README, and the VS Code guide now describe the command and its limits.

## Decisions

- VS Code does not expose a reliable way for this CLI to determine which profile is active in an already-open window. When profiles are ambiguous, the command asks which profile to configure or accepts `--profile`.
- Profile settings are written to the chosen profile; application-wide telemetry, update, and sync settings go to Default Profile settings. GitHub.com account-level privacy controls remain a separate manual step.
