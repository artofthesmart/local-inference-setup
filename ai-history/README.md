# AI session history

Short summaries of AI-assisted work sessions in this repo: what was done, the decisions made and why, and what was verified or left for later.

- One file per session: `YYYY-MM-DD-<short-topic>-<session-id-prefix>.md`.
- Each file has a header (date, session, outcome, references), then **Summary**, **Decisions**, and **Verification and follow-up** sections.
- These are summaries, not transcripts. Never include secrets, personal or customer data, private local paths, or raw logs.
